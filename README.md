# Machine Learning Basics

A collection of Jupyter notebooks demonstrating core Machine Learning concepts, algorithms, and data processing techniques. These projects were developed as part of my coursework in Machine Learning and Artificial Intelligence at AGH UST. 

The repository covers a wide range of ML problems, from baseline regression and classification to handling imbalanced datasets and advanced dimensionality reduction.

## 📓 Notebooks Overview

- **`1-zadanie_domowe.ipynb` (Regression):** Linear Regression, Lasso, Ridge, Huber. Includes data preprocessing, pipelines, imputation, and feature selection.
- **`2-zadanie_domowe.ipynb` (Classification):** K-Nearest Neighbors (KNN), hyperparameter tuning, feature selection, and model evaluation.
- **`3-zadanie_domowe.ipynb` (SVM):** Support Vector Machines classification, cross-validation, pipelines, and parameter tuning (`GridSearchCV`).
- **`4-zadanie_domowe.ipynb` (NLP & Text Classification):** Text processing using `CountVectorizer` and `TF-IDF`, Naive Bayes classification, probability calibration, and pipelines.
- **`5-zadanie_domowe.ipynb` (Imbalanced Data):** Handling class imbalance using oversampling/undersampling (`imblearn`), evaluation metrics (ROC, PR curves), and linear/KNN models.
- **`6-zadanie_domowe.ipynb` (Dimensionality Reduction):** PCA, NMF, KernelPCA, FactorAnalysis. Includes low-dimensional visualizations (t-SNE, UMAP, TriMap) and classification on image datasets.
- **`7-zadanie_domowe.ipynb` (Clustering):** KMeans algorithm, distance metrics analysis, and fundamental clustering techniques.

## 🛠️ Built With

* **Data Processing:** `numpy`, `pandas`
* **Machine Learning:** `scikit-learn`, `scipy`
* **Advanced Techniques:** `imbalanced-learn` (oversampling/undersampling), `umap-learn`, `trimap` (dimensionality reduction)
* **Data Visualization:** `matplotlib`, `seaborn`
* **Data Sources:** `ucimlrepo` (UCI Machine Learning Repository)
